# ✍️ Агент: Content Writer (SEO Продуктови Описания)

Генерира оптимизирани за търсачки продуктови описания на български, подходящи за mostcomputers.bg.

## Стъпки

### 1. Разбери заявката
- Прочети `$ARGUMENTS`:
  - Конкретен продукт (по id, марка или модел)
  - Категория продукти (генерирай за всички без описание)
  - Шаблон за категория (laptop, phone, monitor и т.н.)
  - SEO одит (кои продукти нямат/имат слабо описание)

### 2. Прочети продуктовите данни
- Прочети `products.js` за:
  - `name`, `brand`, `category`, `price`, `specs`, `description` (ако съществува)
  - `badge` — интегрирай в описанието ако е "Ново" или "Топ продукт"
  - `rating`, `reviews` — за social proof елементи
- Прочети `js/seo.js` — разбери как описанията се вграждат в meta тагове
- Прочети `index.html` — провери дали има structured data (schema.org Product)

### 3. SEO одит на описанията
При одит, изведи:
```
✍️ SEO Одит на описания — [дата]

❌ Без описание: [брой] продукта
⚠️  Кратко описание (<100 знака): [брой] продукта
✅ Добро описание: [брой] продукта

Приоритет за писане:
  1. [Продукт] — [причина: няма описание / слабо описание]
  2. ...
```

### 4. Структура на описанието
Всяко описание следва тази структура:

**Кратко описание (meta description, 150-160 знака):**
```
[Марка] [Модел] — [главна полза/характеристика]. [Ключова спецификация]. Поръчай от mostcomputers.bg с бърза доставка.
```

**Пълно описание (за продуктовата страница, 200-400 думи):**
```
## [Заглавие с ключова дума]

[Въвеждащ параграф: за кого е продуктът и каква нужда удовлетворява — 2-3 изречения]

### Защо да избереш [Марка Модел]?

- **[Характеристика 1]:** [Обяснение на ползата за потребителя]
- **[Характеристика 2]:** [Обяснение на ползата за потребителя]
- **[Характеристика 3]:** [Обяснение на ползата за потребителя]

### Технически характеристики

| Спецификация | Стойност |
|--------------|---------|
| [Spec 1]     | [Value] |
| [Spec 2]     | [Value] |

### За кого е подходящ?

[Параграф с целева аудитория — студенти, геймъри, офис работа и т.н.]

Поръчай [Продукт] от mostcomputers.bg и се възползвай от [безплатна доставка / гаранция / бърза обработка].
```

### 5. SEO правила
- **Ключова дума в заглавието** — точния модел + категория (напр. "Lenovo IdeaPad 3 лаптоп")
- **Ключова дума в първото изречение**
- **Локализация** — споменавай "България", "BGN", "Sofia" когато е естествено
- **Избягвай keyword stuffing** — четимост > гъстота
- **Активен глас** — "получаваш", "работи", "постигаш" вместо пасивни конструкции
- **Ползи, не само характеристики** — "16GB RAM = плавен multitasking с 20+ табa"


### 6. Категорийни шаблони

**Лаптопи:**
- Фокус: производителност, батерия, тегло, дисплей
- Целеви аудитории: студенти, работа, гейминг, creative professionals

**Телефони:**
- Фокус: камера, батерия, процесор, дисплей
- Целеви аудитории: фотографи, busy professionals, геймъри

**Монитори:**
- Фокус: резолюция, refresh rate, панел тип, connectivity
- Целеви аудитории: геймъри, дизайнери, офис

**Компютри:**
- Фокус: процесор, RAM, storage, GPU
- Целеви аудитории: геймъри, работа, home use

**Аксесоари:**
- Фокус: съвместимост, качество, цена/стойност
- По-кратко описание (100-200 думи)

### 7. Прилагане на описанията
При одобрение — добави `description` поле в `products.js`:
```javascript
{
  id: "...",
  name: "...",
  description: {
    short: "150-160 знака за meta description",
    full: "Пълното SEO описание..."
  },
  // останалите полета...
}
```

Ако структурата на `products.js` не поддържа `description` — провери как да го добавиш и интегрираш с `js/seo.js`.

### 8. Валидация
- Провери дълг на meta description (не повече от 160 знака)
- Провери, че ключовата дума присъства в title и first paragraph
- Провери четимостта — описанието трябва да звучи естествено на български
- `npm test` за regression след промени в products.js

## Формат на доклада
- Готови описания (copy-paste ready) за всеки поискан продукт
- Кратко (meta) + пълно (страница) описание
- SEO бележки (ключови думи, препоръки)
- Инструкции за интеграция в products.js / seo.js
