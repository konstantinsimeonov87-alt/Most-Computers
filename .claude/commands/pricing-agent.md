# 💸 Агент: Pricing (Ценообразуване)

Управлява ценовата стратегия — промоции, отстъпки, bulk ценови промени и badge логика.

## Стъпки

### 1. Разбери заявката
- Прочети `$ARGUMENTS`:
  - Промоция (конкретни продукти или категория)
  - Bulk ценова промяна (всички продукти или по критерий)
  - Сезонна разпродажба (% отстъпка)
  - Премахване на промоции
  - Ценови одит (намери аномалии)

### 2. Прочети ценовата схема
- Прочети `products.js` за полета `price`, `oldPrice`, `badge`
- Прочети `js/currency.js` за валутна конверсия логика
- Прочети `js/cards.js` за badge/sale визуализация
- Разбери правилата:
  - `oldPrice > price` → показва sale badge и % отстъпка
  - `oldPrice === null` → без sale индикация
  - `badge` стойности: `null | "Ново" | "Намаление" | "Топ продукт"`

### 3. Ценов одит (при поискване)
Провери за:
- Продукти с `price > oldPrice` (грешка — обърнати цени)
- Продукти с `oldPrice === price` (безсмислен sale badge)
- Продукти с отстъпка над 70% (вероятно грешка)
- Продукти с цена 0 или отрицателна
- Ценова последователност в категория (outliers)

### 4. Покажи преглед преди промяна
```
Операция: Промоция -20% на категория "Лаптопи"
Засегнати продукти: 47
Примери:
  - Lenovo IdeaPad 3: 1299 → 1039 BGN (oldPrice: 1299)
  - ASUS VivoBook 15: 999 → 799 BGN (oldPrice: 999)
Общо: 47 продукта ще получат "Намаление" badge
```
Изчакай потвърждение за bulk промени над 10 продукта.

### 5. Приложи ценовата промяна
За промоция:
```javascript
// oldPrice = текуща цена (запазена за сравнение)
// price = нова промоционална цена
// badge = "Намаление"
oldPrice: 1299,
price: 1039,
badge: "Намаление"
```

За премахване на промоция:
```javascript
// Нулирай oldPrice, badge
price: 1299,  // оригинална цена
oldPrice: null,
badge: null   // или "Топ продукт" ако е приложимо
```

### 6. Badge логика
- `"Ново"` — продукти добавени последните 30 дни
- `"Намаление"` — когато `oldPrice > price`
- `"Топ продукт"` — ръчно присвоен за bestsellers
- `null` — стандартен продукт

### 7. Валидация след промяна
- Провери, че % отстъпката се изчислява правилно: `Math.round((1 - price/oldPrice) * 100)`
- Провери, че badge-овете се показват в браузъра
- Провери currency conversion — всички валути трябва да се обновят
- `npm test` за regression

### 8. Документирай промяната
```
Ценова промяна: [дата]
Операция: [тип]
Засегнати: [брой] продукта
Категории: [списък]
Период: [начало] - [край] (ако е временна)
Rollback: [инструкции]
```

## Формат на доклада
- Списък на всички ценови промени (id, продукт, стара цена → нова цена)
- Badge промени
- Потенциални аномалии (ако е одит)
- Rollback инструкции за временни промоции
