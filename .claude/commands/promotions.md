# 🏷 Агент: Promotions Manager

Управлява промоционалните продукти в `dist/js/promotions-data.js` — flash разпродажби, сезонни акции и promo badge-ове.

## Структура

**Файл:** `dist/js/promotions-data.js` → `var promoProducts = [...]`
**Схема:**
```javascript
{
  id: Number,        // продуктово ID (съвпада с основния каталог)
  name: String,      // пълно наименование
  brand: String,     // марка (само от XML feed-овете)
  cat: String,       // категория
  subcat: String,    // подкатегория
  price: Number,     // промоционална цена в EUR (без ДДС)
  sku: String,
  ean: String,
  warranty: Number,  // месеци
  img: String,       // URL към изображение
  badge: 'promo',    // винаги 'promo'
  stock: Boolean,    // true = в наличност
}
```

## Задачи

### Задача 1: Добави продукт в промоция
- Приеми `$ARGUMENTS`: ID или SKU на продукта + промоционална цена
- Провери дали продуктът вече е в `promoProducts` (по id)
- Провери дали `brand` е от одобрените марки в каталога (никога Dell, Apple, HP ако ги няма)
- Генерирай нов запис с `badge: 'promo'`
- Добави в края на масива
- Покажи преглед преди запис

### Задача 2: Премахни продукт от промоция
- Приеми `$ARGUMENTS`: ID или SKU
- Намери продукта в масива
- Потвърди премахването — покажи какво ще се изтрие
- Премахни записа след одобрение

### Задача 3: Bulk update на промоции
- Приеми `$ARGUMENTS`: категория + процент намаление (напр. "laptops -15%")
- Намери всички продукти от категорията в `promoProducts`
- Калкулирай новите цени (закръгли до 2 десетични)
- Покажи таблица: SKU | Стара цена | Нова цена | Промяна
- Изчакай одобрение преди промяна

### Задача 4: Изчисти изтекли промоции (stock: false)
- Намери всички записи с `stock: false`
- Провери дали са повече от 30 дни с `stock: false` (ако има дата)
- Изведи списък за преглед
- Изчакай одобрение преди изтриване

### Задача 5: Одит на промоциите
- Преброй: общо промо продукти / с наличност / без наличност
- Провери за дублирани IDs
- Провери за невалидни цени (price <= 0)
- Провери за липсващи img URL-и
- Провери за марки извън каталога
- Изведи доклад

### Задача 6: Flash sale — бърза акция
- Приеми `$ARGUMENTS`: списък с SKU-та + % намаление + дни валидност
- Генерирай всички записи наведнъж
- Покажи всички за преглед
- Добави след одобрение

## Правила
- Ценовата единица е EUR (евро) — никога лв. като основна
- Само марки от XML feed-овете (никога Dell, Apple, HP извън каталога)
- `badge` е винаги `'promo'` в този файл
- Rebuild не е нужен — promotions-data.js е отделен от app.js bundle
