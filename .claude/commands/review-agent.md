# ⭐ Агент: Review & Ratings

Управлява системата за потребителски ревюта — добавяне, модерация, визуализация и социални доказателства.

## Стъпки

### 1. Разбери заявката
- Прочети `$ARGUMENTS`:
  - Добавяне на ревюта към продукти
  - Обновяване на рейтинги
  - Имплементация на review UI
  - Модерация (премахване на неподходящо съдържание)
  - Одит на review данните

### 2. Прегледай текущата review система
- Провери `products.js` за полета `rating` и `reviews`
- Провери `js/product-page.js` за review rendering логика
- Провери `js/cards.js` за звезди в продуктовите карти
- Провери `index.html` за review секция структура
- Идентифицирай: дали ревютата са статични или динамични (Supabase)

### 3. Продуктов рейтинг одит
Провери `products.js` за:
- Продукти с `rating: 0` и `reviews: 0` (нови продукти)
- Продукти с нереалистични рейтинги (5.0 с 1 ревю)
- Несъответствие между rating и reviews брой
- Продукти без рейтинг в популярни категории

### 4. Bulk обновяване на рейтинги
При добавяне на реални данни:
```javascript
// Формат в products.js
{
  rating: 4.7,    // средна оценка, 1 десетична
  reviews: 23,    // реален брой ревюта
}
```

Правила за рейтинги:
- 1-5 звезди (1 десетична: 4.3, 4.7 и т.н.)
- Минимум 3 ревюта за показване на рейтинг
- Под 3 ревюта → показвай "Бъди първи"

### 6. Schema.org markup за ревюта
```json
{
  "@type": "Product",
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.7",
    "reviewCount": "23",
    "bestRating": "5",
    "worstRating": "1"
  }
}
```
Добави към `js/seo.js` за rich snippets в Google.

### 7. Социални доказателства
- **"X души разгледаха тази страница днес"** — social proof counter
- **"Bestseller в категорията"** — базирано на reviews count
- **"Препоръчан от 95% покупатели"** — изчислено от рейтинг
- **Верифицирано ревю badge** — за потвърдени купувачи

### 8. Модерация
Автоматични правила:
- Скрий ревюта с обидни думи (списък за проверка)
- Маркирай ревюта под 10 символа за ръчна проверка
- Дублирани ревюта от един потребител → само последното

### 9. Тествай
- Провери Schema.org markup с Google Rich Results Test
- Провери звездите се рендерират правилно
- `npm test` за regression

## Формат на доклада
- Одит на рейтинги (продукти с проблеми)
- Schema.org статус
- UI промени
- Социални доказателства имплементирани
