# 📣 Агент: Social Media

Генерира готово за публикуване съдържание за Facebook, Instagram и TikTok от продуктовия каталог.

## Стъпки

### 1. Разбери заявката
- Прочети `$ARGUMENTS`:
  - Промоционален пост за продукт
  - Седмичен контент план
  - Сезонна кампания (Black Friday, Коледа и т.н.)
  - Open Graph оптимизация
  - Продуктова история (Instagram Story)

### 2. Прочети продуктовите данни
- Прочети `products.js` за:
  - Продукти с `badge: "Намаление"` (промоционален потенциал)
  - Продукти с висок `rating` и много `reviews` (social proof)
  - Новодобавени продукти (`badge: "Ново"`)
- Прочети `index.html` за Open Graph тагове
- Прочети `js/seo.js` за meta генерация

### 3. Facebook/Instagram пост формат
```
🔥 [Заглавие — привличащо вниманието]

[Описание на продукта — 2-3 изречения, ползи за потребителя]

✅ [Ключова характеристика 1]
✅ [Ключова характеристика 2]
✅ [Ключова характеристика 3]

💰 Цена: [X] лв (беше [Y] лв — [Z]% отстъпка)
🚚 Безплатна доставка над 100 лв

👉 Поръчай на mostcomputers.bg

#MostComputers #[Категория] #[Марка] #техника #компютри #българия
```

### 4. Instagram Story формат
```
Slide 1: Продукт + голяма цена
Slide 2: Топ 3 характеристики
Slide 3: CTA + "Виж в профила" или link sticker
```

### 5. TikTok/Reels скрипт
```
[0-3 сек]: Hook — "Ако търсиш [продукт] под [цена] лв..."
[3-10 сек]: Показване на продукта и ключова характеристика
[10-20 сек]: Сравнение цена/качество или use case
[20-25 сек]: CTA — "Линк в профила"
```

### 6. Open Graph оптимизация
Провери `index.html` OG тагове:
```html
<meta property="og:title" content="Most Computers — Компютри и Електроника">
<meta property="og:description" content="[compelling description]">
<meta property="og:image" content="[1200×630 image]">
<meta property="og:url" content="https://mostcomputers.bg">
<meta property="og:type" content="website">
```

За продуктови OG тагове в `js/seo.js`:
```javascript
// Динамично OG за продуктова страница
og:type = "product"
og:price:amount = product.price
og:price:currency = "BGN"
og:availability = product.inStock ? "instock" : "oos"
```

```
Категорийни:
  Лаптопи: #лаптоп #лаптопи #notebook
  Телефони: #смартфон #телефон #мобилен
  Гейминг: #гейминг #gaming #геймър
Марки: #lenovo #asus #samsung #apple #nvidia
```

### 8. Контент календар
При заявка за седмичен план:
```
Понеделник: Продуктов spotlight (популярен продукт)
Вторник: Сравнение (продукт A vs продукт B)
Сряда: Образователен пост (как да изберем лаптоп?)
Четвъртък: Промоция/намаление
Петък: "Уикенд оферта"
Събота: Behind the scenes / магазин съдържание
Неделя: User generated content / ревюта
```

### 9. Сезонни кампании
- **Черен петък** (ноември): -X% на категория
- **Коледа** (декември): Gift guide, идеи за подаръци
- **Back to School** (септември): Лаптопи и аксесоари
- **Нова година**: Нов сезон, нови продукти

## Формат на доклада
- Готови постове (copy-paste ready) на български
- Хаштаг списък
- Open Graph препоръки (ако е нужно)
- Контент календар (ако е поискан)
- Препоръки за изображения/видео
