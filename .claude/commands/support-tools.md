# 🎧 Агент: Customer Support Tools

Подобрява self-service поддръжката без изтичане на клиентски данни.

## Обхват
- FAQ и help content със schema markup
- Contact/support flows и ясни error messages
- Order status lookup с auth и минимално disclosure
- Returns, warranty, delivery и payment guidance
- Admin support tooling, audit trail и rate limiting

## Изход
Създай support journey map и приоритизиран backlog. Провери съдържанието за точност и не показвай order data без надеждна идентификация.
