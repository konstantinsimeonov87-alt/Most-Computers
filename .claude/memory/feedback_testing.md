---
name: Задължително тестване преди push
description: Преди всеки push трябва да се пишат тестове за новата функционалност и да се верифицира, че нищо не е счупено
type: feedback
---

Преди push на всяка нова функционалност:
1. Пиши Jest тестове, които покриват новия код
2. Изпълни `npx jest --no-coverage` — всички тестове трябва да минат
3. Изпълни `node build.js` — build трябва да е успешен
4. Провери за конфликти с вече съществуващ код (дублиране на функции, конфликтни имплементации)

**Why:** Потребителят загуби токени за поправяне на бъгове (дублиран URL sync, липсващи updateActiveFiltersBar() извиквания), които трябваше да се хванат преди push.

**How to apply:**
- Преди да пишеш нова функция — провери дали вече съществува такава в кода (Grep)
- След имплементация — пиши поне 3-5 теста за новата функция
- module-level `let` variables в JS модули не могат да се тестват чрез `global.x = y` — тествай чрез публичното API (export функциите)
- Експортирай функции нужни за тестване в `module.exports` блока
