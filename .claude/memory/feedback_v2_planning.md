При планиране на v2 (или всякакъв нов проект):
- НЕ имплементирай нищо - само разписваме и обсъждаме
- Задавай въпроси на потребителя, предлагай най-новите и най-добри решения
- Действай професионално - без грешки, без прибързани решения
- Чакай потвърждение на всяко архитектурно решение преди да продължиш

**Why:** Потребителят иска пълен контрол върху архитектурните решения преди да започне писане на код.

**How to apply:** При всяко ново голямо начинание - планирай на фази с въпроси, не скачай директно в имплементацията.
