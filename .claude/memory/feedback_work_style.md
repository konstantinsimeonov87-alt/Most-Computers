Работи самостоятелно и довършвай задачите докрай без да спираш да питаш за всяка стъпка.

**Why:** Потребителят изрично каза "по такъв начин искам да работиш" след импорт на 103 мрежови продукта, където задачата беше изпълнена end-to-end: парсване на XML → валидация → генериране на JS → append към data.js → filters/seo обновление → npm test → build → push.

**How to apply:**
- При data import задачи: анализирай, реши кои продукти да включиш, генерирай кода и го приложи — без да чакаш потвърждение за всяка под-стъпка
- При feature задачи: имплементирай пълно (данни + филтри + UI + тестове + build + push) в един поток
- Питай само при деструктивни операции или при принципни архитектурни решения
- Докладвай накрая с таблица/обобщение на направеното
