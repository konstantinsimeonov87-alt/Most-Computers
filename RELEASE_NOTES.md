# Most Computers — Release Notes v1.7.0
**Дата:** 2026-05-18

---

## Новости

- 🖨️ **173 нови продукта — Canon консумативи** — тонери и мастиленоструйни касети с пълна навигация в новата категория „Консумативи"
- 🔄 **Cross-sell в продуктовата страница** — под галерията виждате подходящи консумативи за вашия принтер
- ⚡ **„Остават само N бр."** — индикатор за ограничена наличност на популярни продукти
- 🛒 **Qty stepper в търсачката** — добавяте/намалявате количество директно в search dropdown без да отваряте продукта
- 🏠 **Начална страница** — секциите са наредени по-логично: категории → промоции → нови продукти → bestsellers → пълен каталог

## Подобрения

- Breadcrumbs в категорийните страници (Home → Категория → Субкатегория)
- Sticky CTA bar в продуктовата страница при scroll
- Прогрес бар за безплатна доставка в кошницата
- Autocomplete за Econt градове при checkout
- Spec copy бутон в продуктовите спецификации (копира стойност)
- Wishlist price-drop нотификации при намаление на запазен продукт
- Сайтът зарежда с **21% по-малко HTML** след build оптимизация

## Поправки

- Flash sale grid запълва реда коректно при нечетен брой продукти
- Подобрена сигурност при рендериране на продуктови снимки от external домейни

## Достъпност

- Таблиците (работно време, сравнение на продукти, спецификации) вече отговарят на WCAG 2.1 Level A за screen readers

## Most Computers — Release Notes v1.6.0
**Дата:** 2026-04-20

---

## Новости

- 🗄️ **Реална база данни** — поръчките вече се записват в облачна база (Supabase). Нищо не се губи при рестарт.
- 📧 **Имейл нотификации** — при нова поръчка администраторите получават автоматичен имейл
- 📦 **XML импорт с подкатегории** — при импорт на продукти от доставчик може да се избере подкатегория директно в preview прозореца
- 🛒 **Upsell в кошницата** — кошницата показва свързани продукти, за да улесни избора
- ⚡ **По-бързо зареждане** — admin панелът се зарежда само при нужда (136 KB по-малко при старт)

## Поправки

- XML импорт по URL работи коректно — отстранен проблем с CORS proxy
- Филтрите в категорийните страници работят правилно за "Процесори", "Видеокарти" и др.
- Марките в sidebar вече не показват "(undefined)" за празни категории
- Проблем с корупция на продуктови данни в браузъра — напълно решен с нова merge стратегия

## Сигурност

- Допълнителна XSS защита в страницата 404 и в резултатите от търсене
- Подобрена достъпност (WCAG 2.1 AA): search полето и навигацията са по-достъпни за screen readers
- Тъмен режим: цветовият контраст на допълнителни текстове увеличен до 6.3:1
