Какво се премахва (3 елемента)

Какво се опростява (4 елемента)
Категории Grid → само на mobile (CSS media query)

Промо банери → Split Banner или Dynamic Banner, не и двата наведнъж

Нови продукти табове → "Тази седмица / Последния месец"

Brands Bar → 8-10 лога, статично, без ticker
📈
Очакван резултат
Потребителят вижда по-бързо Flash Sale и продуктите без да "разчита" три ленти с еднаква информация.

Намален cognitive load — по-малко решения "кое промо да кликна".

Hero → Trust → Sale → Нови → Bestsellers е ясен conversion path без прекъсвания.
